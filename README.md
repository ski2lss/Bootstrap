# ДЗ 14.1 — адаптивный макет Bootstrap

Простой сайт с фотографиями Карпат.

- Три колонки LEFT / MAIN / RIGHT: 3/6/3 на большом экране, 4/8 и отдельный RIGHT на среднем, одна колонка на маленьком.
- HEADER с двухуровневым меню.
- LEFT: слайдер из четырех вертикальных фотографий 800 × 1100.
- MAIN: аккордеон с советами.
- RIGHT: форма обратной связи с пятью подписанными полями и кнопками.
- FOOTER со ссылкой наверх.

Открыть index.html или использовать Live Server. Bootstrap 5.3.3 находится в vendor; собственный JavaScript не используется.

Форма учебная. Браузер проверяет обязательные поля и email. CSS :target показывает сообщение после завершения. Сервер не подключен, у полей нет name, поэтому их значения не передаются в адресной строке.
